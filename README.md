# Hi, I'm Rob

**Software Test Engineer.** I write test automation, and I like it to be stable and readable, have very clear failure logs, and to look cool. I guess technically the latter is optional, but engineers need to learn that aesthetics are important. This page collects the live CI results, two test projects, and notes on how I work. Check out the live results to see the sort of test reporting you could share with any stakeholder or coworker.

Explore within to find the kind of projects I think are interesting and specifically how I use AI in my workflow to punch above my junior level while maintaining strict quality. (The short of it is that I use AI in the IDE, usually in learning mode, to build pieces out one at a time, with clear and concise AGENTS.md files. With a test framework and debugging utilities in place, an agent can extend the pattern and create new tests and page objects entirely on its own when handed a ticket with proper context, acceptance criteria, and repro steps. Always review code before pushing to main!)
